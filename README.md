# JamLuPOS

Enterprise POS & Inventory Management System (partial): Login, Dashboard, Inventory CRUD.

Stack: C#, Windows Forms, .NET Framework 4.8, SQL Server.

## Setup
1. Open Database/01_CreateDatabase.sql in SSMS and run it once (creates the lucero database).
2. Open JamLuPOS.slnx in Visual Studio 2019/2022.
3. Edit Data Source in JamLuPOS/App.config if your server is not localhost.
4. Build and run (F5).
